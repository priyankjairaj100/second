Exact reference core — 4 October 2026

Implemented in exact_core.py:
- Exact reverse LDL decomposition H=L^T diag(t)L, bottom-right pivots.
- The declared fixed-grid sequential rational quantizer; midpoint ties lower.
- A conditional relative-spectral rounding certificate using the normalized
  shape constant (b-a)^2/(4ab), with exact squared cell inequalities.
- Explicit zero-displacement ties, saturation cells and singleton grids.
- A per-record PSD spectral-interval sum for deletion; no square roots.
- Numeric inputs restricted to integers/Fraction, with no float conversion.

The caller MUST rigorously establish a Hbar <= Htrue <= b Hbar. The module
does not establish this premise. accepted=True is conditional on that premise.
The result targets this mathematical rational recurrence, not floating-point
program E. Dense arithmetic operation counts are O(d^3+p d^2) for fixed grids;
Fraction bit complexity and all full-service costs are additional.

Intentionally not implemented here:
- A full-model sequential repair service or activation-transport bounds.
- Authentication of inputs, record IDs, traces or covariance sources.
- Canonical repeated-deletion state and storage/disposal transactions.
- Sparse target-factor change injection (separate derivation needed).
- A benchmark, GPU kernel, model download or empirical speedup claim.

Validation scope: static Python compilation only. No numerical tests,
synthetic examples, real-model experiments or timing runs were executed.
Experiments remain paused by the user's instruction. Static/manual review
does not establish a tested implementation; numerical verification remains
required when experiments resume.
