Revision 3, 4 October 2026.

Implemented standard-library reference modules:
- exact_core.py: exact reverse LDL, sequential rational rounding, shape-cell certificate.
- sparse_repair.py: changed-code injections and exact ambiguous-coordinate fallback.
- response_moments.py: exact affine response moment index and canonical deletion.
- response_certificate.py: squared error descriptors and exact outward bounds.
- linear_response.py: O(r d²+r²) Gram-response index, PSD omission, signed/shifted enclosures.
- repair_service.py: complete fixed-DAG fresh/repair paths, canonical state, proposal provenance, adaptive replay.
- response_service_adapter.py: trusted intrinsic response/extractor integration; per-record descriptor storage and scans explicitly charged.
- transformer_backend.py: complete pinned scalar CPU decoder, exact dyadic features/logits, service integration, structural identity certificates.
- work_scheduler.py: standalone cooperative bounded-work fallback scheduler.

Behavioral, independent-oracle, adversarial and integration correctness tests
were run. See docs/VALIDATION.md for the final result and test log. Static
compilation and report visual checks also completed. These are software
verification, not research benchmark or synthetic dataset results.

Not implemented/established:
- automatic certified neural jets, curvature, residual and nontrivial finite
  transport for realistic pretrained checkpoints;
- compact group-aggregated response state inside the complete service (the
  standalone index is aggregate, but the transparent adapter retains and scans
  per-record payloads);
- pretrained model adapters, production GPU kernels or scheduler integration;
- equality to unrelated floating Gram/Cholesky target E;
- useful real-model acceptance, latency or memory/amortization results;
- physical memory erasure, hostile-store authentication, or formal verification.

Trusted callback numerical/provenance premises stay visible. UNKNOWN causes
exact retained replay. Correctness does not imply speedup. Old raw experiment
files remain unavailable. Research experiments remain paused.
