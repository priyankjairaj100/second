Selected historical audit receipts: review derivatives

These nine JSON files are labelled derivatives of preserved execution receipts.
Identifying absolute paths are replaced consistently by REVIEW_PATH_####. The
same eight exposed evaluation articles retain Q01--Q08 across these receipts and
the development-evidence summary. Other historical article identifiers, if any,
use REVIEW_ARTICLE_####. No raw article/token/model/state binary is included.

Every original JSON number, Boolean, null, array order and field is preserved.
Only selected string values/object keys change. A private reverse map verifies
exact typed-object roundtrips and collision rejection. Original byte commitments
and this private mapping are not included here. Embedded source/input/artifact
hashes still refer to ORIGINAL execution objects: a redacted path does not satisfy
the corresponding original binding. Do not execute these copies as registrations.
