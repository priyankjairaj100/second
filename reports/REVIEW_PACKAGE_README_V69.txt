Historical claim boundaries
The nearest-anchor pooled quality guard failed even though its maximum-article
guard passed. The later original-checkpoint screen is adaptive development.
The original-checkpoint service saves approximately9% live state with compression,
but is39--42% slower than cached lossless; the hybrid first endpoint is stronger.
The modern lossless artifact adds only0.14% storage savings. These refer to distinct
audited historical campaigns. The currently running new-root service has no final
result and is not represented as completed evidence in any of these components.

What the checks establish
The manifests and offline verifier check bytes and inventories. The source checker
exercises generated local fixtures; production numerical/runtime/Slurm boundaries
are mocked. Source adaptations, summary derivations and receipt string mappings
have separate private provenance records. None of these operations reruns actual
model/state audits, acquires the untouched frame or establishes empirical quality.

Review exclusions and remaining release work

registrations, machine logs, raw article/token records, model/state binaries and
environment installations are excluded. Tiny generated source fixtures remain.
