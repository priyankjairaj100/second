model_gate.py restores actual packed bytes on frozen row grids, checks original
checkpoint stage-weight words and wraps the unchanged V55 sequential constructor.
The first-stage invariant is checked at both retained endpoints. Candidate codes
never enter sequential features. Original normalization and production geometry
remain obligations of the eventual worker.

construction_flow.py fixes the13x128 root, exact12/6 retained suffixes and token
commitments. Each endpoint gets a separate exclusive output directory, complete
progress, packed codes and diagnostics. Failures preserve partial progress and
refusal diagnostics. Its audit reparses actual codes and compares metadata and
progress. It does not independently repeat calibration or settle runtime costs.

parameter_audit.py compares every actual saved NPZ array with the checkpoint
reference, including embeddings, positions, norms, biases, head and stage weights.
It checks canonical manifest/config, unique uncompressed archive members, bounded
NPY headers before allocation, exact array extents and all binary64 words.
Checkpoint provenance must be established by the caller. A self-consistent
archive/hash alone cannot establish that provenance.

model_backend.py uses the frozen V61 target validator, actual checkpoint parameter
words and four complete packed endpoint models. It builds all six evaluator roles
with their actual prefix-word bindings. Nearest rounding uses the unchanged lower
midpoint tie rule. CPU evaluation uses the frozen NumPy implementation. The CUDA
factory requires a fresh process, one device, deterministic cuBLAS, float64,
TF32/AMP disabled and an explicit allocator cap. Every transferred tensor passes
its frozen bitwise round-trip check. There is no CPU fallback. Real CUDA runtime
qualification, actual parameter export provenance and job admission remain open.

reference files, checks the parity barrier/progress order and recomputes paired
statistics. It rejects missing, extra or changed artifacts and wrong prediction
counts, including records after the parity subset. It shares the statistics
implementation and does not independently rerun inference. Actual model/runtime,
ledger, scheduler, complete CPU and GPU accounting still need terminal workers.
