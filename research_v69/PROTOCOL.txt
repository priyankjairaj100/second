Evaluator and statistical contract
Use the unchanged shared ordinary NumPy/Torch binary64 likelihood semantics,
128-token sequences and127 predictions each. This is approximate likelihood,
not certified neural inference. CUDA uses one admitted device, no AMP or TF32,
deterministic algorithms and CUBLAS_WORKSPACE_CONFIG=:4096:8 before initialization.
All parameter and replacement-array transfers receive bitwise CPU round-trip
checks. Keep the runtime/driver/device inventory and actual peak allocator bytes.
Use V68's fixed320-article,20000-draw paired bootstrap and fixed PCG64 seed.
Both endpoints require pooled PPL ratio<=1.05, one-sided97.5% bootstrap upper<=1.05,
and observed maximum article ratio<=1.20. These are approximate bounded-frame
uncertainty statements, not population-tail guarantees. Do not increase the sample
or change guards after observing quality. Original and nearest controls run once.
The loss audit must receive the GPU NumPy version from the frozen runtime, not
infer it from an untrusted statistics file. Record the recomputation runtime
separately. Every numeric statistic and gate decision must match exactly; only
the two legitimate runtime-provenance fields are allowed to differ. An arithmetic
disagreement is a failed audit, with no silent tolerance or repeated attempt.

cost_accounting.py verifies persisted worker seals/artifacts/applied limits and
actual ledger debits, parses terminal scheduler allocation rows without adding
