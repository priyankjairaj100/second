Four technical corrections

1. Step 3 now applies only to an unresolved stage. A request stops only when that
   stage remains uncertified after any permitted replay. Already certified stages
   do not trigger the stopping branch.
2. The coefficient at the feature-box center is now c^0_ih. The generic interval
   center retains its previous symbol; the text explicitly specializes the
   propagation formula to c^0_ih for the archive-width argument.
3. Source inspection found that the service disables rational fallback. Both its
   maximum exact rank and exact-coordinate count are zero; point numerical
   refinement has a sixteen-coordinate cap. Lower-level solver defaults of 64/16
   do not describe the service call. V122's vague reference to separate bounds is
   replaced with these actual limits. See src/adaptive_calibration_v30.py and
   research_v43/dispatcher.py; V112 preserves this point solver under its route
   policy. No original implementation or resource limit was changed.
   The codec step is now explicit: for index precision p=48 and block exponent
   e_b=max floor(log2(abs(x))), step=2^max(e_b-p+2,-1074). Zero receives exponent
   -1074. Signed indices use floor(x/step); the existing exact-value/escape rules
   remain. The source is src/fixed_factor_codec_v26.py.
4. For s>0 the square-root check normalizes a=s*2^(-e) in [1/2,2), with even e.
   It accepts finite nonnegative r only when nextdown(fl(r*r)) >= a and rescales
   by 2^(e/2). There are at most eight tested proposals, starting with sqrt(a),
   rather than eight additional upward moves. Zero returns zero. This matches
   the frozen primal_certificate_v30 Python and native implementation.
