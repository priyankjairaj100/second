Review findings addressed before registration
The CPU runtime does not expose the CUDA runtime's top-level executable field.
Interpreter commands are therefore bound separately and checked against actual
sys.executable; CPU binary identity still comes from the unchanged inherited runtime.
The current worker's live debit cannot be mistaken for a missing predecessor debit.
Only its verified admission ID may coexist with otherwise completed predecessors.
GPU allocator/transfer reports are read after device-context exit, when final peaks
and roundtrip counts exist. The real quality route requires318 array roundtrips.
The historical CPU wrapper sets four thread variables, while the new gate requires
seven. That wrapper remains frozen; a separately registered V69 wrapper is required.
