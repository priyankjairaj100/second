## ExecCert retrieval gap closed

[ExecCert, version 1](https://arxiv.org/html/2610.02268v1) was available in full text during this check.
Earlier audits could inspect only its abstract.
We inspected Sections 4.1–4.4, Appendix C's structure, and Sections E.1–E.3.

Its Lemma 1 bounds error using a corrected residual and an inverse defect.
Its reference-transfer mechanism tracks stored statistics against the exact retained system.
Its Theorem 1 includes guarded transitions and atomic certification of the released artifact.
It also derives margin-based decision agreement.
Its comparisons include fresh and maintained verified factors.
Its lifecycle study charges update work and varies release frequency.

Therefore, executable certificates, maintained numerical evidence, margin-based agreement, and lifecycle accounting cannot be claimed as our new general ideas.
Our possible distinction is exact adaptive quantizer-code equality for every feature matrix represented by compressed calibration evidence.
That distinction still requires useful empirical cost and storage results.
We have not reproduced ExecCert's implementation or compared every theorem assumption.

## Method positioning

The strongest candidate contribution remains exact output recovery from uncertain calibration evidence.
Neither a fast cache nor source-local features alone provides sufficient novelty.
A certificate must save useful storage or computation under the same output contract.
The full model must retain useful language behavior.
The full service must preserve the correct successor state.

The V39 Gram controls use exact integer accumulation in Python.
Their shared row kernel removes one important implementation mismatch.
Their timings cannot establish dominance over every optimized Gram representation.
A stronger control should accumulate exact Grams with native integer arithmetic.
The new V40 factory implements this path and preserves canonical archive bytes.
It must still pass a real-data comparison against the Python reference.
Arbitrary floating matrices cannot assert their own positive semidefinite provenance.

This control is software-tested, not an executed empirical baseline.
No conclusion from V39 should depend on omitting it.
The small pilot remains useful for finding numerical failures and choosing the next representation.
