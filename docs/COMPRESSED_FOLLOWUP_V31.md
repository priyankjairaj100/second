# Native verification and finer feature enclosures

This is an adaptive development follow-up to the completed V30 pilot.
The V30 results, registrations, and source snapshots remain unchanged.
V30 produced exact model codes and a smaller state, but failed its latency gate.
Repair took 312.326876080 seconds, compared with the fastest cold time of 140.549491491 seconds.
Only 22 of 24 stage certificates succeeded.
The other two stages collectively required all 24 retained neural traversals.
Python coefficient checks also consumed substantial time before that replay.

The new worker changes two mechanisms prospectively.
Strict native interval arithmetic replaces Python coefficient loops.
Forty-eight-bit descriptors replace forty-bit descriptors throughout the state.
The nominal block step decreases by a factor of 256 unless the minimum-subnormal floor binds.
This does not guarantee numerical certificate acceptance.
The new state must still contain every original finite feature value.
Every returned model must match the same retained-only fixed-feature target.

The point solver, fixed grids, original normalization, and ordered decoder remain unchanged.
Certificate memory stays at one GiB; point memory stays at 512 MiB.
Sparse refinement keeps its existing work and coordinate limits.
The service retains exact replay and explicit refusal.
No certificate receives reference codes or exact retained factors.

The phase measures fresh conversion and one complete repair.
It charges conversion in addition to original lossless preparation.
Promotion requires exact output, smaller state than lossless, and faster complete repair than every recorded cold repeat.
The lossless repair time and forty-bit state remain visible comparators.
Beating cold reconstruction alone does not imply dominance over the lossless method.
This paired intervention does not isolate a causal precision effect from a kernel effect.

The numerical kernel and worker require independent review before registration.
The specification is `campaigns/compressed_service_v31.spec.json`.
Do not infer registration, completion, or success from this design note.
