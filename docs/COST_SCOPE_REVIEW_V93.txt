Source finding: fallback extraction is nested, not an additive phase

research_v61/service.py starts the per-stage timer at line193. If a compressed
certificate is refused, the retained-source traversal at line233 occurs before
that stage's elapsed time is recorded at line248. The traversal also increments
source_extraction_ns. Adding source_extraction_ns to the sum of stage elapsed
values would count that interval twice. This is a reporting pitfall identified
from source; it is not evidence that any running request has fallen back or that
an already published result contains this error. Historical sources stay intact.

For the compressed/modern stored-state requests used by V89/V92, report the
following disjoint accounting in integer nanoseconds, after actual closure:
  outside request = complete host elapsed - request elapsed
  predecessor validation = timing.predecessor_validation_ns
  stage work including fallback = sum(timing.stages[*].elapsed_ns)
  serialization = timing.serialization_ns
  disposal = timing.disposal_ns
  unattributed request time = request elapsed - the four internal entries above
These entries sum to complete host elapsed. Reject a negative remainder, an
incomplete/duplicate stage census or a request larger than its host envelope.
Stored-state requests do not prepare new payloads: encoding_and_gram_ns is zero.
Source extraction and source-stage/record pairs are separate diagnostics. Without
fallback both must be zero. With fallback, extraction is inside a fallback stage.
The outside-request interval contains multiple operations and is not exclusively
startup. The remainder includes unseparated admission, reads/writes, book-keeping
and other gaps; it must not be renamed I/O, decoding, validation or solver cost.

Decoder time is not separately timed in these records. The stage timer combines
weight preparation, descriptor/array work, solving and code construction; archive
validation and serialization may also decode. Do not infer a decoder-only time,
a precise decoder share, or an Amdahl speedup limit from the stage total. Nested
solver diagnostics remain separate unless their non-overlap is demonstrated.

Source finding: the optimized cells bundle multiple changes

research_v79/implementation.py lines100-108 enables token-neighbor optimization
in both optimized cells, plus native compressed decoding in one and canonical
modern-lossless reuse in the other. Therefore reference-to-optimized complete
request ratios measure the combined package within each representation. They do
not isolate the causal contribution of the decoder or cache alone. Earlier
component experiments have their own scopes and do not replace full requests.
