## Target contract

The empirical method repairs calibration membership for a fixed pretrained checkpoint.
It does not remove information from that checkpoint's original pretraining.
The fixed nearest-grid anchor is independent of deletable calibration membership.
Each record's finite anchor features are deterministic and source-local.
Binary64 feature values are interpreted as exact dyadic numbers after their specified computation.
Grids, coordinate order, ridge, and original normalization belong to the frozen target.
The midpoint rule chooses the lower code.
The numerical verifier either certifies the target or refuses without an incorrect committed model.

The target differs from standard sequential GPTQ.
Earlier repaired stages do not change later fixed-anchor calibration features.
Fresh reconstruction must use the same frozen normalization, anchor, and grids.
Changing those rules defines another target and invalidates an unchanged-target equality claim.
Model equality and canonical persistent-state equality are separate obligations.

## Proof-to-code checks for the next service

1. Bind every stage to the same immutable target and original normalization.
2. Derive trusted Grams only through admitted exact construction and checked algebra.
3. Authenticate compressed source identity and verify containment during preparation.
4. Treat nominal solves as proposals; verify residuals and directed error bounds.
5. Preserve adaptive prefix induction, saturation cells, and exact midpoint rules.
6. Verify complete code extent before atomic release.
7. Charge all fallback ancestors, including already accepted stages traversed during replay.
8. Rebuild successor state independently from retained inputs under one canonical schema.
9. Test deletion order, duplicate requests, empty retention, and missing-source refusal.
10. Preserve failed attempts and report any bounded refusal without treating it as successful repair.

These are concrete implementation obligations.
Passing arithmetic fixtures does not discharge complete-service obligations.
Matching output hashes does not establish independent state construction or competitive quality.

## Baselines and interpretation

Its Gram control also exposes the weakness of a cache-only speed claim.
V40 tests a compiled exact accumulator with the same archive semantics.
Every compatible comparator should receive this improvement.
The streamed adapter removes concatenation; it does not itself compress stored state.
Select future representations using declared access, storage, and numerical costs.
