## Output-format obstruction

A complete fully represented dense state has a separate, proved serialization obstruction.
One group needs at least 67,239,936 Gram entries, alongside 42,467,328 model code entries.
Each rational pair needs at least five bytes under the existing encoding.
Thus the specified state needs at least 548,536,320 bytes, or 523.125 MiB.
This already exceeds the 512 MiB single-file cap, before separators and metadata.
Absent responses and new encodings can escape the bound; it is not universal impossibility.
The audit states every assumption and the current identity-cache exception boundary.

A new packed or factorized state representation is required for the intended complete-state experiment.
Faster finite arithmetic alone cannot solve that output-format obstruction.
