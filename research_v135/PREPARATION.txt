Minimal source-only persistent representation contains the deployed packed codes,
complete frozen target manifests, retained tokens or references and provenance.
It stores no features, descriptors or Gram. Byte count includes actual tokens in
"tokens" mode. That mode can replay after external corpus disappearance and must
not be described as dependent on external retained-source access. "references"
mode calls an explicit retained-record provider and refuses when unavailable or
when token identities differ. Neither mode permits deleted-record traversal.

Eight generated tests cover both formats, source availability, exact words,
canonical successor serialization, deletion membership, model corruption and
rejection of hidden caches. These are format tests, not empirical validation.

was corrected before registration to read the bound anchor's row_scale_hex.
